# To-Do

Список задач на чистом JavaScript: создание, редактирование, удаление, статусы,
поиск, сортировка по сроку и ручной порядок с drag-and-drop. Интерфейс полностью
на русском, данные хранятся в браузере.

## Возможности

- Создание задачи с названием и необязательным сроком.
- Отметка выполнения с визуальным состоянием и прогрессом.
- Редактирование названия и срока прямо в строке задачи.
- Удаление задачи с отменой действия.
- Очистка всех выполненных задач с отменой действия.
- Фильтры «Все», «Активные», «Выполненные» со счётчиками.
- Поиск по названию без учёта регистра.
- Сортировка: «Мой порядок», «Дата: сначала ранние», «Дата: сначала поздние».
- Ручной порядок перетаскиванием: мышь, touch-экраны и клавиатура.
- Сохранение задач и порядка в `localStorage`, синхронизация между вкладками.
- Адаптивная вёрстка от 320 px, тёмная тема, поддержка клавиатуры и скринридеров.

## Стек

- JavaScript: ES-модули, DOM API, без фреймворков и сборки.
- CSS: Grid, Flexbox, custom properties.
- `localStorage` для хранения состояния.
- Node.js: локальный статический сервер без зависимостей.

## Запуск

Нужен Node.js 18 или новее.

```bash
npm start
```

Приложение откроется по адресу [http://localhost:4174](http://localhost:4174).
Сборка не требуется: файлы отдаются как есть. Открывать `index.html` напрямую
из файловой системы нельзя, потому что браузер заблокирует ES-модули.

## Управление

| Действие | Мышь / touch | Клавиатура |
| --- | --- | --- |
| Новая задача | Поле ввода и «Добавить» | `n`, затем `Enter` |
| Поиск | Поле «Поиск по названию» | `/` |
| Очистить поиск | Кнопка в поле поиска | `Escape` |
| Редактировать задачу | Кнопка с карандашом | `Enter` в форме, `Escape` для отмены |
| Переместить задачу | Ручка `⠿` и перетаскивание | `Alt` + `↑` / `↓` на ручке |
| Отметить выполненной | Чекбокс | `Space` на чекбоксе |

В режимах сортировки по дате ручки перемещения скрываются, потому что порядок
в этом режиме определяется сроком. Ручной порядок при этом не теряется.

## Данные

Задачи хранятся в `localStorage` под ключом `to-do-list.tasks` в версионированной
схеме. При чтении данные проверяются: некорректные записи отбрасываются,
дубликаты идентификаторов исправляются. Изменения в одной вкладке подхватываются
в другой через событие `storage`.

## Структура

```text
.
├── index.html                 # каркас страницы и подключение модуля
├── scripts/serve.js           # локальный статический сервер
├── src/
│   ├── main.js                # точка входа
│   └── js/
│       ├── app.js             # сборка приложения и состояние интерфейса
│       ├── store.js           # задачи, localStorage, порядок
│       ├── dom.js             # помощники для DOM API
│       ├── icons.js           # встроенные SVG-иконки
│       ├── components/        # шапка, форма, список, задачи, тосты
│       └── utils/             # даты и склонение числительных
└── styles/main.css            # тёмная тема и адаптивная вёрстка
```

## Деплой

Проект статический, поэтому подходит любой хостинг статики. Для GitHub Pages
в репозитории настроен workflow, который публикует содержимое ветки `main`
без шага сборки. После включения Pages в настройках репозитория приложение
будет доступно по адресу:

```text
https://katharine-posh.github.io/web-to-do-list/
```
