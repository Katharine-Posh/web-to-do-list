# ToDo-лист

ToDo-лист, где пользователь может создавать, редактировать и удалять задачи, отмечать их как выполненные, фильтровать, сортировать и искать задачи по дате и названию, а также менять порядок задач с помощью drag-and-drop.

## Стек

- JavaScript (ES-модули, DOM API)
- CSS (Grid, Flexbox, custom properties)
- `localStorage` - хранение задач
- Node.js — локальный статический сервер без зависимостей

## Запуск

```bash
npm start
```

Приложение откроется по адресу [http://localhost:4174](http://localhost:4174).
